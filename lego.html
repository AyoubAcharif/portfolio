Lego Bricks Length Sensing

During our industrial computing studies, the entire 2nd-year class collaborated on a project spanning Project Management, Technical English, Database, Embedded Systems, and Web Development courses. My team, comprising Mathias and me, focused on automation in the industrial landscape, aligning with the industry's growing reliance on efficiency-enhancing technologies.

Our project involved creating a website to display real-time information on a conveyor: brick length, detection date, and time. The Arduino embedded system captured data transmitted to the Raspberry Pi, requiring precise calibration for accuracy. The website featured a history tab and sensor details, whereas the embedded system displayed measurements on an LCD screen with a reset button.

Challenges arose in remote work, hindering realistic testing without access to the conveyor and sensors. Despite a 7-day timeline, external factors required additional effort beyond school hours. Backend tasks included integrating a reset button, automating data refresh, and contemplating a "favorites" system for bookmarking measurements.

This project refined my skills in collaborative problem-solving, project management, embedded systems development, and web design. Overcoming remote work challenges strengthened adaptability and troubleshooting abilities. The experience illuminated the intricacies of industrial automation, offering practical insights into real-world applications and the importance of precise calibration in measurement systems.
