Ge-Ga Project

As part of my Industrial Computing course at HELHa, I was required to do an internship in a company, which was the subject of my final year project. I completed my internship at the IRE (Institut des Radioéléments), where I was given a project for the R&D (Research and Development) team, called ‘Ge-Ga Project’.

The main goal of this project was to centralise specific production and operating data for Ge/Ga generators in an SQL Server database. This data came either from different types of files (Excel, CSV or PDF) or from manual encoding (carried out at the time in Excel files).

The R&D team also wanted to have a way of encoding different data directly into the database, while benefiting from a high degree of flexibility, so being able to display, insert, modify and delete data. The goal was to implement a reporting system based on this database, to generate usable reports or graphs.

Initially, the project was to be developed entirely in Python, for both the frontend and the backend. After careful consideration with the IT team, it was decided to design a full-stack project, including a web application, a Python application on the backend, and an SQL Server database.

The web application offered a more user-friendly interface, as desired by the R&D team, making it easier to work on the frontend. The Python application, meanwhile, was used to process the various files to send them to the database.
